### Защита состояния Hero

Почему методы ПР №2 не защищали от прямой записи в поле:

поля были public поэтому Program.cs можно было написать alexander.Health = -100; и обойти любые методы

Чем отличаются get, set и private set:
get разрешает читать значение
set разрешает и читать и записывать
private set разрешает только внутри самого класса

Где проверяется начальное здоровье:
в конструкторе hero с ограничением MaxHealth

Как Heal сохраняет границу MaxHealth:
missingHealth = MaxHealth - Health;

Как Name использует поле \_name и значение value:
value - то что записываем , код проверяет , обрезает пробелы , сохраняет результат

Почему в конструкторе используется Name = name:
потому что присвоение шло через свойство Name
если написать \_name == name проверка будет пропущена
